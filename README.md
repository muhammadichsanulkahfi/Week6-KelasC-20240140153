# PPAW Week 6 – JavaScript DOM, Event Handling, dan Fetch API

Tugas individu. Buka `index.html` di browser (disarankan via Live Server).

## Fitur
1. **Fetch API** – mengambil produk dari `https://dummyjson.com/products`, menampilkan nama, harga, kategori, dan gambar lewat DOM. Ada status loading, penanganan error, tombol muat ulang, dan pencarian.
2. **Form Pemesanan** – event `input`, `change`, `submit`, `click`; validasi nama, email, paket, jumlah; total harga dihitung otomatis; hasil ditampilkan dinamis.

## Struktur
- `index.html`
- `style.css`
- `script.js`
